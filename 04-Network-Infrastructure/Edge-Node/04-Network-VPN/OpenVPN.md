# OpenVPN

- Home ASUS router: VPN server.
- Caleb node: VPN client.
- Interface: `tun0`.
- Preferred behavior: split tunnel.
- Internal Alabama services should not be exposed directly to the public Internet merely to support Caleb.

Legacy Friday VPN start/stop timers remain present only as **disabled historical units**. The current Local Events maintenance schedule is Sunday/Wednesday and must not be replaced by those old Friday timers.

VPN profiles, certificates, private keys and passwords are intentionally excluded from GitHub.
