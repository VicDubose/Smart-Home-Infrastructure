# Edge Storage Behavior

Caleb's local SSD is a **cache with a reserve**, not an archive that must mirror every Jarvis title.

Future catalog-state language:

- **Available locally** — playable from Caleb's Edge storage.
- **Available from Jarvis** — authoritative copy exists remotely.
- **Can download/sync locally** — eligible for reverse sync when capacity allows.
- **Needs processing** — raw or unfinished media is still in the pipeline.

If Caleb's disk is full, the correct outcome is *Jarvis-only for now*, not pipeline failure.
