# Caleb Media Command Center

The production Lovelace dashboard is titled **Caleb Media Command Center** and focuses on Jellyfin and ingest operations.

It presents:

- node/Jellyfin/VPN health,
- active Jellyfin streams/transcodes,
- CPU, memory, disk and temperature telemetry,
- ingest disc/stage/progress/message,
- recent errors,
- storage details,
- pipeline state,
- library/recently-added context.

A sanitized dashboard snapshot is preserved under `12-Reference-Snapshot/home-assistant/`.
