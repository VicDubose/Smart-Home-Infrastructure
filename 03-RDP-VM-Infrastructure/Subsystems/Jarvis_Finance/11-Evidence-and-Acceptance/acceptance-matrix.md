|---|---|---|
| G0 — Specialist contracts | Exact version, hash, ownership, compatible changes | Partial / component-specific |

| G8 — Recovery | Failure, timeout, stale data, restart, idempotent replay | Open |
| G9 — Release authorization | Separate Master review and explicit advisory approval | Not granted |

## First useful finish line

Reliable cash-flow and debt visibility requires fresh Regions/SoFi evidence, daily Actual extraction with upstream bank freshness, monthly Nelnet evidence or an explicit last-verified label, C reconciliation, and a truthful saved dashboard snapshot.

Gusto Stage 2 PDF automation is optional and does not block this first finish line.

## Full intelligence finish line

The full system additionally requires D unattended source collection, general E deterministic acceptance, real central policy binding, bounded RAG use, guarded model evaluation, and end-to-end scheduler-to-dashboard recovery tests.

Financial execution is outside Finance V1.
