# Jarvis Implementation Reference

This directory contains versioned reference snapshots copied from the live
SKYNET-CORE implementation.

These files are NOT the production execution paths.

Production authority remains the live Jarvis Core and live Home Assistant
systems. These copies exist so Jarvis documentation and RAG can understand
the code that implements the documented architecture.

Sections:

- Disk-Burning-and-Media
- Local-Events
- Harness-Core
- Systemd

Generated runtime state, logs, databases, caches, media files, credentials,
and secrets are intentionally excluded.
